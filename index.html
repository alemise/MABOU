Partager l’application MABOU

Envoyez MABOU à une autre personne pour qu’elle puisse l’ouvrir sur son téléphone ou son ordinateur.

Le partage transmet le fichier de l’application, pas les données de votre commerce. Chaque appareil conserve ses propres données.

Pour partager le fichier, téléchargez MABOU puis envoyez le fichier MABOU.html par WhatsApp, Bluetooth, e-mail ou une autre application compatible. Pour une installation Android comme une application, une version APK sera nécessaire.
