MABOU Gestion — projet Android

Ce dossier est un projet source Android Studio qui embarque votre fichier HTML dans une WebView.
Il est conçu pour fonctionner hors ligne et conserver les données dans le stockage local du navigateur intégré.

Pour générer l'APK :
1. Installer Android Studio sur un ordinateur.
2. Ouvrir le dossier MABOU_Android dans Android Studio.
3. Attendre la synchronisation Gradle et installer les composants Android SDK proposés.
4. Choisir Build > Build Bundle(s) / APK(s) > Build APK(s).
5. Récupérer l'APK dans app/build/outputs/apk/debug/.

Important :
- Ce paquet est le projet source, pas encore un fichier APK compilé.
- Testez l'application et faites une exportation JSON de vos données avant toute mise à jour.
- La fonction d'impression peut nécessiter des ajustements selon le téléphone et l'imprimante.
