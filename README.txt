MABOU - Projet Android (WebView hors connexion)

Ce dossier est un projet source Android Studio qui embarque MABOU.html localement.
Il ne s'agit pas encore d'un APK compilé.

Pour générer l'APK :
1. Installer Android Studio sur un ordinateur.
2. Ouvrir le dossier MABOU_Android dans Android Studio.
3. Attendre la synchronisation Gradle et installer les composants SDK proposés.
4. Choisir Build > Build Bundle(s) / APK(s) > Build APK(s).
5. Récupérer l'APK dans app/build/outputs/apk/debug/.

Note : l'application stocke ses données dans le stockage local du WebView. Testez l'application et faites une sauvegarde avant de désinstaller ou de changer de téléphone.
