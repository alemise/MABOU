MABOU Gestion — projet Android avec la version enrichie

L'application web intégrée est la version enrichie avec panier multi-produits, saisie de dates, actions de modification/suppression et profils utilisateurs locaux.

Ceci est le code source Android, pas un APK compilé. La compilation et les essais nécessitent Android Studio/Gradle sur un ordinateur.
Les profils utilisateurs ne disposent pas encore de permissions détaillées; la synchronisation entre appareils n'est pas activée.
Faites une sauvegarde de vos données avant de remplacer une ancienne version.
